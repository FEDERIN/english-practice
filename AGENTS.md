# AGENTS.md

## Descripción del repositorio

Este repositorio contiene notas personales de estudio de inglés. Los archivos de notas son archivos Markdown (`.md`) con vocabulario, reglas gramaticales y ejercicios. El archivo `reglas_ingles.md` consolida las reglas de inglés extraídas de las notas. También incluye `app/`, una PWA en React para practicar en el iPad mini 2.

## Estructura

- `reglas_ingles.md` — Índice de reglas de inglés.
- `presente_simple.md` — Reglas del presente simple.
- `presente_continuo.md` — Reglas del presente continuo.
- `there_is_there_are.md` — Reglas de There is / There are y Some vs Any.
- `how_many_how_much.md` — Reglas de How many / How much.
- `vocabulario.md` — Vocabulario general y entradas pendientes.
- `modales.md` — Modal verbs (can, could, should, must, may, shall).
- `adjetivos.md` — Adjetivos.
- `app/` — PWA en React (interfaz en inglés) con ejercicios, constructor de oraciones (evalúa gramática y naturalidad por separado), flashcards y notas; ver `app/APP_README.md`.
- `mcp_practica/` — Servidor MCP que genera ejercicios desde los `.md`.
- `AGENTS.md` — Este archivo.

## Convenciones

- Los archivos de notas usan el formato `palabra => traducción` o `palabra --> traducción`.
- Las reglas gramaticales se documentan en español con ejemplos en inglés.
- Al agregar nuevas notas, mantener el formato existente y actualizar `reglas_ingles.md` con las nuevas reglas.

## Tareas típicas

- Agregar vocabulario nuevo a los archivos `.md`.
- Corregir errores gramaticales en los textos de práctica.
- Actualizar `reglas_ingles.md` cuando se agreguen nuevas reglas.
- Mantener la organización por secciones en `reglas_ingles.md`.
