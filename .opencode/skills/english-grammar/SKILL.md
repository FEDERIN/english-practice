# English Grammar Notes

This repository contains personal English study notes. Each grammar topic has its own markdown file (e.g. `simple_present.md`, `simple_past.md`, `simple_future.md`). The index is `reglas_ingles.md`.

## Adding an example

When the user shares an example sentence, validate that it is grammatically correct, then append it to the `## Examples` section of the relevant topic file. If no `## Examples` section exists, create one before the final `## Watch out` section.

Format: one bullet per example, `- Sentence.`

## Adding a new topic

1. Create a new file named in English using snake_case: `<topic>.md` (e.g. `present_continuous.md`).
2. Follow the existing structure:
   - `# Title`
   - `## When to use it` (numbered list with English example + meaning)
   - `## Form` (affirmative / negative / question)
   - `## Common time markers`
   - `## Examples` (bullets)
   - `## Watch out`
3. Add the file to the index list in `reglas_ingles.md`.
4. Add a consolidated summary block in `reglas_ingles.md`.

## Validation

Always check that shared examples are grammatically correct before adding. If incorrect, explain the error and provide the corrected version, then add the corrected one.

## Language

All `.md` content is in English. The index `reglas_ingles.md` keeps its existing Spanish headings but entries and consolidated rules may be bilingual.
