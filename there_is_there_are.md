# There is / There are (Hay)

## Uso
- Indicar existencia de personas, cosas o lugares.

## Estructura
- **There is** → singular (hay + singular)
  - There is a fridge in my house.
  - There is a bed in my bedroom.
  - There is one elephant.
  - There is a sandwich on my plate.
  - There is an orange in the fridge.
  - There is a hospital in my country.
  - There is nothing in my fridge.
  - There isn't anything in my fridge.
- **There are** → plural (hay + plural)
  - There are pillows on my bed.
  - There are two computers on the table.
  - There are five people in the house.
  - There are three children in the class.
  - There are ten chairs at school.
  - There are many things in my fridge.

## Negativas
- There isn't an apple on the counter.
- There's not a dog in the garden.
- There aren't any children at school.
- There are not any fruits on my counter.

## Preguntas
- Is there any water in the bottle?
- Are there any people outside?
- Are there any students in the classroom?
- Is there an apple on the counter?
  - Yes, there is.
- Are there children in the car?

## Some vs Any
- **some** → ofertas / peticiones
  - Do you have some bread?
  - Would you like some cookies?
  - Can I get you some water?
  - Can I borrow some pencils?
- **any** → preguntar si existe algo
  - Do you have any bread?
  - Is there any water in the bottle?
  - Are there any people outside?

## Regla de números
- Singular: There is + a/an + sustantivo singular.
- Plural: There are + número + sustantivos en plural.

## Pasado: There was / There were (Había / Hubo)
- **There was** → singular o incontable (había/hubo + singular)
  - There was a beautiful dog.
  - There was some bread on the table.
  - There was a lot of traffic this morning.
- **There were** → plural (había/hubo + plural)
  - There were a lot of accidents.
  - There were several photos on the wall.
  - There were many birds on the roof.
- Negativas: There wasn't / There weren't (también: There was not / There were not).
  - There wasn't any money to buy food.
  - There weren't any clean plates on the table.
- "Some" en afirmativas y "any" en negativas/preguntas también aplican en pasado.
  - There was enough food for everyone.
  - There were some plants in the sink.

## Ejercicios de práctica: pasado (con corrección)
- There was a beautiful dog.
- There was a woman at the door.
- There was a lot of traffic.
- There were a lot of accidents.
- There was some bread on the table.
- There was a lion in the zoo.
- There was rice in the pot.
- There was a lot of traffic this morning.
- There was enough food for everyone, but we didn't buy food this week.
- There wasn't any money to buy food.
- There wasn't enough orange juice.
- There were a lot of students in the classroom.
- There were some plants in the sink, but there weren't any clean plates on the table.
- There were many birds on the roof, but there weren't any in the nest.
- There were several photos on the wall, but there weren't any photos of them.
